# 토론 메뉴와 진행 수명

## 목적과 적용 범위

기본 타이머의 실시간 공유·속기록·답변 시간과 토론 중 로그아웃의 동작을 정의함. 피드백·사회자 투표·종료 화면에는 토론 메뉴를 제공하지 않음. 타이머 자체의 진행 규칙은 [타이머 위키](timer.md), 공용 언어·음량은 [설정 위키](settings.md)가 소유함.

**지식 상태:** 2026-11-12 MP-03 계획 대화와 구현 요청으로 승인한 목표 정책임. MP-03의 독립 UI·훅·Story를 MP-04에서 실제 헤더·페이지에 연결하고 기존 버튼·자동 속기 동의 팝업을 교체했음. 구현·서버 연동·배포 완료는 구분함.

## 기능별 정책

| 기능             | 동작                                                                                                                                                                  |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 공통             | 메뉴 순서는 실시간 공유 → 속기록 → 답변 시간임. 메뉴 밖에는 비활성화·활성화·오류를 이름과 함께 표시함. 처리 중과 원인·복구 행동은 메뉴 안에서 제공함                  |
| 공유 시작        | 확인 이후 토큰 발급·연결을 시작함. 연결 완료 전 활성화로 표시하지 않음. 메뉴 열기·링크 보기만으로 시작하지 않음                                                       |
| 공유 끄기        | 연결 중이면 `ABORT` 발행을 시도한 뒤 이 기기의 연결·구독·자동 재연결을 정리함. 사회자 타이머·속기는 유지함. 로컬 발행 실패는 오류로 표시함                            |
| 공유의 보장 범위 | 발행 성공은 서버 중단 확정을 뜻하지 않음. 성공 확인·응답 유실 후 상태 복원·새 청중 차단·구버전 호환은 후속 요구로 유지함                                              |
| 속기 시작        | 녹음 동의·RPC/Soniox 선택·마이크 테스트를 거쳐 시작함. 최초 활성화 시도의 인식 언어를 고정하며 UI 언어 변경·재시도로 바꾸지 않음. 모드는 최초 활성화 성공 후 잠금     |
| 속기 끄기        | 마지막 구간과 기존 초안을 보존하고 같은 페이지에서 재활성화하면 이어 기록함. 권한·수집 오류 재시도는 이후 기록을 재개하며 유실된 구간을 복원했다고 표시하지 않음      |
| 답변 시간        | 최초 켜짐·30초임. 15/30/45/60초를 선택함. 끄면 실행·표시를 초기화하고 버튼·Shift를 차단함. 선택값은 유지하고 다시 켜면 대기함                                         |
| 답변 시간 변경   | 실행 중에도 즉시 적용함. 기존 경과 시간이 새 제한 이상이면 새 제한에서 정지하고, 아니면 경과 시간을 보존함. 차례·진영 변경·주 타이머 정지는 기존 초기화 조건을 유지함 |

회원 여부·기능 권한·브라우저 지원 조건을 유지함. 사용할 수 없는 기능은 이유를 안내하고 토큰 발급·녹음을 시도하지 않음. 공유·속기·답변 시간은 전역 설정에 저장하지 않음.

## 로그아웃과 기록

- 경고 취소는 인증·타이머·공유·속기·초안을 유지함.
- 확인하면 추가 진행 입력을 차단하고 타이머·답변 시간·마이크 테스트·수집을 정리함. 해당 토론의 미제출 로컬 초안을 폐기하고 마지막 구간의 새 전사·기록 제출을 시작하지 않음.
- 공유 중단은 로컬 발행을 시도하고 정리하며 서버 확인을 기다리지 않음. 설정의 최종 변경도 발행만 하고 응답을 기다리지 않음.
- 로그아웃 API 성공 뒤 인증을 정리함. 실패하면 인증을 유지하고 재시도를 제공하며, 기능과 폐기한 초안을 자동 복원하지 않음.
- 늦은 전사 결과는 삭제·교체된 초안을 만들거나 덮어쓰지 않음. 이미 제출된 서버 기록은 삭제하지 않음.
- 일반 끄기·정상 종료는 폐기와 구분함. 정상 종료는 마지막 전사 보존·대기·제출 성공 후 초안 정리를 유지함.

## 조작과 이탈

메뉴를 닫아도 기능은 유지함. 오버레이는 포커스 순환·복귀·닫기를 제공하고 본문 단축키를 차단함. 확인 취소는 메뉴의 해당 조작으로 복귀함. 입력·버튼의 키를 본문 타이머 조작으로 중복 처리하지 않음.

인증 상실·계정 변경은 수집을 중단하고 해당 세션을 폐기함. 일반 이탈은 기존 속기 이탈 확인을 유지하며 언어 접두어 변경은 이탈로 취급하지 않음. 탭 닫기·오프라인의 서버 중단 전달은 보장하지 않음.

## 현재 연결 상태와 근거

- [제어 훅](../../../src/page/TimerPage/hooks/useDebateControls.ts)·[메뉴](../../../src/page/TimerPage/components/DebateMenu.tsx)·[로그아웃 훅](../../../src/page/TimerPage/hooks/useDebateLogout.ts)을 MP-04에서 페이지 수명에 연결했음.
- 기본 타이머는 메뉴에서 공유·속기·답변 시간을 조작하며 설정 로그아웃을 중단 콜백으로 연결함. 실제 계정·마이크·서버 검증과 배포 완료는 별도로 확인함.
- 청중의 `handleAbort`를 실제 화면에서 켜고 수신 사유를 같은 테이블의 종료 방문에 전달함. 없는 사유를 서버에서 복원하지 않으며 직접 방문은 [중립 안내](navigation.md#완료종료-안내)를 표시함.
- 정책 변경 근거는 [결정 기록](../decisions/debate-controls.md#debate-controls-dec-001--mp-03-준비-범위와-중단-정책), 기술 계약은 [구조와 UI](../../architecture/structure-and-ui.md)·[데이터 접근](../../architecture/data-access.md)·[실시간 통신](../../architecture/realtime.md)을 따름.

MP-04의 실제 연결·서버 보장 범위와 승인 근거는 [공통 결정](../decisions/shared.md#shared-dec-001--mp-04-헤더탐색청중-완료-연결)을 따름.
