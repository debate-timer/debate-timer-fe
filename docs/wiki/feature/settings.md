# 전역 설정

## 목적과 제공 기능

회원과 비회원이 표시 언어·종소리 음량을 일관되게 선택하고, 설정 모달에서 문의 링크와 로그인·로그아웃에 접근하는 기능임. 헤더·설정 모달·빠른 음량 조절·종소리가 같은 적용값을 사용하도록 하는 것을 목표로 함.

**지식 상태:** 확정 정책은 [전체 작업 계획](../../../master-plan.md)에 사용자 답변을 반영한 목표이며 아직 화면에 반영되지 않은 내용도 포함함. 구현 제안·미확정 질문과 코드에서 확인한 사실은 별도로 표시함. 위키 작성으로 제안을 승인하거나 구현·배포 완료를 의미하지 않음. 상태의 효력은 [위키 유지보수 기준](../maintenance.md#지식의-상태와-근거)을 따름.

MP-02 구현·테스트·리뷰의 제품 기준으로 사용함. 요청·응답, 캐시, 저장 처리와 상태 소유권의 기술 계약은 [데이터 접근](../../architecture/data-access.md)과 [구조와 UI](../../architecture/structure-and-ui.md)가 소유함. 후속 결정의 근거는 [설정 결정 기록](../decisions/settings.md)에 남김.

## 주요 개념과 관계

| 개념 | 의미 |
| --- | --- |
| 전역 설정 | 화면 간에 공유하는 표시 언어·음량임. 개별 토론의 실행 상태와 구분함 |
| 적용값 | 현재 화면·종소리에 실제 사용하는 값임 |
| 저장값 | 회원 서버 또는 비회원 브라우저 저장소에 보존한 직접 선택값임 |
| 명시한 링크 언어 | 방문한 링크가 지정한 언어임. 앱이 자동으로 붙인 접두어와 구분함 |
| 직접 선택 | 언어 선택기·음량 조절에서 사용자가 값을 변경하는 행동임 |
| 언어 미선택 | 계정 저장 언어가 `null`인 상태임. 한국어를 직접 선택한 상태와 다름 |
| 저장 상태 | 적용값의 저장 진행·성공·실패를 구분함. 적용됐다는 사실만으로 저장 성공을 의미하지 않음 |

설정 모달은 공용 설정의 조작 진입점이며 별도의 적용값이나 저장 작업 수명을 소유하지 않는 것을 목표로 함.

## 기본 동작

아래는 목표 흐름이며 현재 UI의 구현 완료를 의미하지 않음.

1. 접속·로그인 상태와 링크 언어에 따라 초기 언어·음량을 결정함. 회원은 본인 서버 설정을 조회하고 비회원은 브라우저 저장값을 사용함.
2. 사용자가 헤더·설정 모달·빠른 음량 조절에서 직접 선택하면 공용 적용값을 바꾸고 해당 사용자 영역에 저장함.
3. 저장 실패는 적용값과 구분해 알리고 재시도를 제공함. 기본값·자동 감지값을 직접 선택처럼 서버에 저장하지 않음.
4. 모달 닫기·앱 내부 화면 이동으로 최종 대기 저장을 잃지 않게 함. 계정 변경·로그아웃에서는 이전 계정의 요청을 분리함.

## 조건별 정책과 예외

### 설정 대상과 모달 영역

**확정 정책·목표:** 전역 설정 대상은 표시 언어·음량임. 답변 시간·공유·속기 활성화 상태는 전역 설정에 저장하지 않음.

- 모달에는 일반 설정(언어·음량), 설정된 문의 링크, 계정 영역을 제공함.
- 계정 영역은 비회원에게 로그인, 회원에게 로그아웃을 제공함. 로그아웃 진입점은 설정 모달로 모음.
- 헤더와 모달의 언어 변경, 빠른 음량과 모달의 음량 변경은 같은 공용 동작을 사용함.
- 문의는 일반 문의·템플릿 추가 요청·단체/제휴 문의를 다룸. 별도의 문의 접수 API는 만들지 않음.

설정 진입점의 화면별 배치는 전체 작업 계획의 헤더 적용 범위를 따름. 청중 헤더의 언어·로그인 제공을 근거로 설정·로그아웃까지 제공한다고 확대하지 않음.

### 회원·비회원과 계정 전환

**확정 정책·목표:** 회원은 본인 서버 설정, 비회원은 브라우저 저장소를 사용함.

- 로그인할 때 비회원 값을 계정으로 자동 이전하지 않음.
- 회원 A·회원 B의 설정·캐시·대기 요청과 비회원 값을 분리함. 다른 계정의 응답이 현재 계정 값을 덮어쓰지 않게 함.
- 로그아웃하면 브라우저가 원래 가지고 있던 비회원 값으로 복귀함.
- 계정 변경·로그아웃 시 이전 계정의 대기 저장을 새 계정 인증으로 전송하지 않음.
- 다른 기기에서 바꾼 설정의 실시간 동기화는 이번 범위 밖임.

### 표시 언어의 우선순위

**확정 정책·목표:** 한국어(`ko`)·영어(`en`)를 지원하며 다음 순서로 결정함.

1. 명시한 링크 언어
2. 회원 계정의 저장 언어 또는 비회원이 직접 선택해 저장한 언어
3. 지원하는 브라우저 언어
4. 한국어

- 접두어 없는 경로는 링크 언어 미지정임. `/ko`는 명시한 한국어로 먼저 적용한 뒤 기본 언어 접두어를 정규화함.
- 자동 감지·정규화로 앱이 붙인 접두어를 명시한 링크 언어로 취급하지 않음.
- 링크 방문·자동 감지는 저장 요청을 만들지 않음. 직접 선택만 화면·URL·저장소에 반영하며 query·hash를 보존함.
- 회원 설정 조회 전에는 브라우저 언어 → 한국어로 표시하고 조회 후 계정 언어를 적용함. 명시한 링크 언어와 조회 중 직접 선택한 값은 늦은 조회 응답으로 덮어쓰지 않음.
- 계정 언어 미선택(`null`)은 브라우저 언어 → 한국어로 대체함. 자동 대체값을 계정에 저장하지 않음.
- UI 언어 변경은 타이머·공유·속기를 재시작하거나 진행 중인 음성 인식 언어를 바꾸지 않음.

URL·언어 감지와 동기화의 구현 계약은 [앱·라우팅·국제화](../../architecture/app-routing-i18n.md)를 따름. MP-02에서 위 목표와 기존 구현의 차이를 함께 반영해야 함.

### 음량과 즉시 적용

**확정 정책·목표:** 내부 음량은 0~1의 유한값·소수 1자리이며 두 번째 소수 자리에서 반올림함. 기본값은 0.5이고 기존 UI의 0~10 표시는 경계에서 변환함.

- 빠른 음량·모달·종소리는 같은 적용값을 즉시 사용함.
- 회원 저장은 서버의 정규화된 최종 응답으로 저장 결과를 확인함. 상세 요청·응답은 데이터 접근 문서를 따름.
- 값이 없을 때의 기본값을 회원의 직접 선택값처럼 임의 저장하지 않음.

### 저장 수명과 실패 복구

**확정 정책·목표:** 적용값과 저장값·저장 상태를 구분함.

- 조회·저장 실패는 지역 UI에서 복구하고 재시도를 제공함. 실패를 저장 성공으로 표시하지 않음.
- 조회 실패 상태에서 기본값으로 기존 서버 설정을 덮어쓰지 않음.
- 모달 닫기·앱 내부 화면 이동으로 최종 대기 저장을 잃지 않게 함. 실패 표시는 모달을 다시 열어 확인할 수 있어야 함.
- 접속·로그인 때 필요한 초기 조회 이후 포커스 복귀·재연결·주기적 자동 재조회를 하지 않음.

**구현 제안·미확정:** 전체 작업 계획에는 서버 저장을 500ms 지연으로 묶고 조작 완료 시 최종값을 저장하는 안이 있음. 연속 변경의 요청 순서와 요청 중 추가 변경을 이어 저장하는 방식은 MP-02에서 구체화할 대상임. 기존 종소리 훅의 500ms 로컬 저장 구현이 이 전역 저장 정책의 승인 근거는 아님.

탭 닫기·오프라인에서 대기 저장이 서버에 반드시 전달된다고 보장하지 않으며, 해당 상황의 안내·복구 방식은 미확정 질문에 남김.

### 문의·모달 조작과 로그아웃 경계

**구현 제안·미확정:** 문의 URL을 공용 환경 설정에서 읽고 trim 후 빈 항목은 헤더·모달에서 숨기는 안임. 모두 없으면 문의 메뉴·영역도 숨기는 예외를 제안함. 실제 변수명·표시 조건의 확정은 MP-02에서 수행함.

**구현 제안·미확정:** 전역 설정을 중앙 모달로 제공하고 키보드·포커스 복귀·닫기를 지원하며 입력 중 본문 단축키를 차단하는 안임. 배치·겹침·전체 화면의 구체적인 상호작용은 구현 시 검증함.

기본 타이머에서 진행 중 로그아웃의 경고·공유·마이크 정리는 페이지가 소유하고 설정 모달은 이를 위임하는 진입점임. MP-03에서 연결하며, 취소 시 진행 유지와 로그아웃 실패 시 인증을 먼저 지우거나 성공 이동하지 않는 목표를 따름. 공유 중단의 성공 확인·상태 복원은 MP-01 기본 통신의 완료 범위에 포함되지 않았음.

## 대표 사용 흐름·예시

아래는 목표 정책을 적용한 예시이며 실제 브라우저에서 확인한 동작은 아님.

- 계정 저장 언어가 한국어인 회원이 영어 링크를 방문하면 영어로 표시하되 계정 언어는 바꾸지 않음. 이후 언어 선택기에서 영어를 직접 선택하면 계정에 저장함. 근거는 [언어 우선순위](#표시-언어의-우선순위)임.
- 비회원 음량이 0.2인 브라우저에서 음량 0.8을 저장한 계정으로 로그인하면 계정 값을 사용함. 로그아웃하면 비회원의 0.2로 복귀함. 근거는 [계정 전환](#회원비회원과-계정-전환)임.

## 현재 구현과 목표의 차이

**구현에서 확인한 사실:** MP-01 로컬 구현 기준이며 실제 서버 연동·배포 완료를 의미하지 않음.

| 영역 | 현재 확인한 사실 | 남은 차이 |
| --- | --- | --- |
| 회원 통신 | 설정 조회·부분 수정 API와 MSW가 있음 | 전역 설정·모달과 연결해야 함 |
| 서버 상태 | 계정별 캐시·지연 응답 보호·지역 오류·수동 재시도 기반이 있음 | 인증 수명과 공용 적용값·저장 상태를 연결해야 함 |
| 음량 | 종소리 훅이 브라우저 저장과 타이머 음량을 소유함 | 모달·빠른 음량·종소리가 공용 설정을 사용해야 함 |
| 언어 | 경로·브라우저·로컬 감지와 자동 캐시를 사용함 | 링크 방문·직접 선택을 구분하고 회원 설정과 연결해야 함 |
| 설정 모달 | MP-01은 모달 UI를 구현하지 않았음 | 일반·문의·계정 영역과 접근성 동작을 구현해야 함 |

근거는 [회원 API](../../../src/apis/apis/member.ts), [설정 조회 훅](../../../src/hooks/query/useGetMemberSettings.ts), [설정 변경 훅](../../../src/hooks/mutations/usePatchMemberSettings.ts), [종소리 훅](../../../src/page/TimerPage/hooks/useBellSound.ts), [i18n 초기화](../../../src/i18n.ts), [언어 선택기](../../../src/layout/components/header/LanguageSelector.tsx)임.

## 인접 기능과의 경계

| 기능 | 전역 설정과의 경계 |

## 결정 근거와 미확정 질문

### 목표 정책의 근거

기존 목표의 근거는 전체 작업 계획 4절의 헤더·설정 모달, 전역 설정·언어, 로그아웃 사양과 6절의 설정 지연 저장·화면 이탈 조건임. 해당 계획은 2026-11-11 사용자 답변을 반영했다고 명시함. 이번 대화에서 사용자는 MP-02 구현 전 전역 설정 위키를 작성해 기준으로 두도록 요청했음. 명시적 구현 제안은 확정 정책으로 승격하지 않았음.

[설정 결정 기록](../decisions/settings.md)은 현재 작성 양식만 준비한 상태임. 후속 결정 시 실제 승인 주체·일자·근거와 해당 정책 절을 연결함. 확인되지 않은 과거 결정일·이유를 복원해 채우지 않음.

### MP-02에서 확인할 질문

| 항목 | 이미 정해진 경계 | 추가로 결정할 내용 |
| --- | --- | --- |
| 초기 조회 실패 | 기본값으로 서버 설정을 덮어쓰지 않음 | 조회 복구 전 언어·음량 조작과 저장 허용 범위 |
| 비회원 저장소 실패 | 회원 서버 저장과 비회원 저장을 분리함 | 현재 탭의 적용값 유지·안내·복구 방식 |
| 저장 실패 표시 | 적용값·저장 상태를 구분하고 재시도 가능해야 함 | 자동/수동 재시도와 미저장 상태의 구체적인 표시 |
| 저장 시점·페이지 종료 | 내부 이동·모달 닫기로 최종 저장을 잃지 않음 | 500ms 지연안·조작 완료 시점과 탭 닫기·오프라인 안내·복구 |
| 문의·모달 제안 | 문의·계정 진입과 공용 설정을 제공함 | 미설정 문의 숨김 예외와 모달 상호작용 제안의 구체화·확정 |

질문과 제안은 관련 구현 전에 결정하며 미정 동작을 테스트의 확정 기대 결과로 사용하지 않음.

## 검증 근거와 한계

[회원 API 테스트](../../../src/apis/apis/member.test.ts)와 [설정 훅 테스트](../../../src/hooks/query/useGetMemberSettings.test.tsx)는 HTTP·모의 저장·계정별 캐시·지연 응답·재시도 기반의 근거임. 모달·언어 우선순위·비회원 복귀 구현 완료의 근거는 아님.

MP-02에서는 위 목표와 질문 해소 결과로 회원·비회원 전환, 링크·저장 언어 충돌, 조회 중 직접 선택, 공용 음량, 모달 닫기·화면 이동 중 저장, 실패·재시도, 포커스·단축키·전체 화면을 검증해야 함. 실제 서버 저장·재로그인과 브라우저 저장소 실패도 모의 검증과 구분함.

이번 문서 작성에서는 문서·코드 근거와 링크를 확인했으며 기능 테스트·브라우저 검증·서버 연동·배포는 수행하지 않았음.
