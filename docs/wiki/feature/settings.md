# 전역 설정

## 목적과 제공 기능

회원과 비회원이 표시 언어·종소리 음량을 일관되게 선택하고, 설정 모달에서 문의 링크와 로그인·로그아웃에 접근하는 기능임. 헤더·설정 모달·빠른 음량 조절·종소리가 같은 적용값을 사용하도록 하는 것을 목표로 함.

**지식 상태:** 확정 정책은 2026-11-12 MP 작업 계획 대화의 사용자 답변을 반영한 목표이며 아직 화면에 반영되지 않은 내용도 포함함. 구현 제안·코드에서 확인한 사실은 별도로 표시함. 위키 작성으로 제안을 승인하거나 구현·배포 완료를 의미하지 않음. 상태의 효력은 [위키 유지보수 기준](../maintenance.md#지식의-상태와-근거)을 따름.

MP-02 구현·테스트·리뷰의 제품 기준으로 사용함. 이번 대화에서 해소한 질문은 아래 보완 정책을 따름. 요청·응답, 캐시, 저장 처리와 상태 소유권의 기술 계약은 [데이터 접근](../../architecture/data-access.md)과 [구조와 UI](../../architecture/structure-and-ui.md)가 소유함. 후속 결정의 근거는 [설정 결정 기록](../decisions/settings.md#settings-dec-001--mp-02-전역-설정과-저장-정책)에 남김.

## 주요 개념과 관계

| 개념             | 의미                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------- |
| 전역 설정        | 화면 간에 공유하는 표시 언어·음량임. 개별 토론의 실행 상태와 구분함                    |
| 적용값           | 현재 화면·종소리에 실제 사용하는 값임                                                  |
| 저장값           | 회원 서버 또는 비회원 브라우저 저장소에 보존한 직접 선택값임                           |
| 명시한 링크 언어 | 방문한 링크가 지정한 언어임. 앱이 자동으로 붙인 접두어와 구분함                        |
| 직접 선택        | 언어 선택기·음량 조절에서 사용자가 값을 변경하는 행동임                                |
| 언어 미선택      | 계정 저장 언어가 `null`인 상태임. 한국어를 직접 선택한 상태와 다름                     |
| 저장 상태        | 적용값의 저장 진행·성공·실패를 구분함. 적용됐다는 사실만으로 저장 성공을 의미하지 않음 |

설정 모달은 공용 설정의 조작 진입점이며 별도의 적용값이나 저장 작업 수명을 소유하지 않는 것을 목표로 함.

## 기본 동작

아래는 목표 흐름이며 현재 UI의 구현 완료를 의미하지 않음.

1. 접속·로그인 상태와 링크 언어에 따라 초기 언어·음량을 결정함. 회원은 본인 서버 설정을 조회하고 비회원은 브라우저 저장값을 사용함.
2. 사용자가 헤더·설정 모달·빠른 음량 조절에서 직접 선택하면 공용 적용값을 바꾸고 해당 사용자 영역에 저장함.
3. 직접 선택은 즉시 적용하며 저장 실패에도 적용값을 유지함. 조회·저장 상태와 재시도 버튼은 모달에 표시하지 않음. 기본값·자동 감지값을 직접 선택처럼 서버에 저장하지 않음.
4. 모달 닫기·앱 내부 화면 이동으로 최종 대기 저장을 잃지 않게 함. 계정 변경·로그아웃에서는 이전 계정의 요청을 분리함.

## 조건별 정책과 예외

### 설정 대상과 모달 영역

**확정 정책·목표:** 전역 설정 대상은 표시 언어·음량임. 답변 시간·공유·속기 활성화 상태는 전역 설정에 저장하지 않음.

- 모달에는 일반 설정(언어·음량), 설정된 문의 링크, 계정 영역을 제공함.
- 계정 영역은 비회원에게 로그인, 회원에게 로그아웃을 제공함. 로그아웃 진입점은 설정 모달로 모음.
- 헤더와 모달의 언어 변경, 빠른 음량과 모달의 음량 변경은 같은 공용 동작을 사용함.
- 문의는 일반 문의·템플릿 추가 요청·단체/제휴 문의를 다룸. 별도의 문의 접수 API는 만들지 않음.

설정 진입점의 화면별 배치는 전체 작업 계획의 헤더 적용 범위를 따름. 청중 헤더의 언어·로그인 제공을 근거로 설정·로그아웃까지 제공한다고 확대하지 않음.

### 회원·비회원과 계정 전환

**확정 정책·목표:** 회원은 본인 서버 설정, 비회원은 브라우저 저장소를 사용함.

- 로그인할 때 비회원 값을 계정으로 자동 이전하지 않음.
- 회원 A·회원 B의 설정·캐시·대기 요청과 비회원 값을 분리함. 다른 계정의 응답이 현재 계정 값을 덮어쓰지 않게 함.
- 로그아웃하면 브라우저가 원래 가지고 있던 비회원 값으로 복귀함.
- 계정 변경·로그아웃 시 이전 계정의 대기 저장을 새 계정 인증으로 전송하지 않음.
- 다른 기기에서 바꾼 설정의 실시간 동기화는 이번 범위 밖임.

### 표시 언어의 우선순위

**확정 정책·목표:** 한국어(`ko`)·영어(`en`)를 지원하며 다음 순서로 결정함.

1. 명시한 링크 언어
2. 회원 계정의 저장 언어 또는 비회원이 직접 선택해 저장한 언어
3. 지원하는 브라우저 언어
4. 한국어

- 접두어 없는 경로는 링크 언어 미지정임. `/ko`는 명시한 한국어로 먼저 적용한 뒤 기본 언어 접두어를 정규화함.
- 자동 감지·정규화로 앱이 붙인 접두어를 명시한 링크 언어로 취급하지 않음.
- 링크 방문·자동 감지는 저장 요청을 만들지 않음. 직접 선택만 화면·URL·저장소에 반영하며 query·hash를 보존함.
- 회원 설정 조회 전에는 브라우저 언어 → 한국어로 표시하고 조회 후 계정 언어를 적용함. 명시한 링크 언어와 조회 중 직접 선택한 값은 늦은 조회 응답으로 덮어쓰지 않음.
- 계정 언어 미선택(`null`)은 브라우저 언어 → 한국어로 대체함. 자동 대체값을 계정에 저장하지 않음.
- UI 언어 변경은 타이머·공유·속기를 재시작하거나 진행 중인 음성 인식 언어를 바꾸지 않음.

URL·언어 감지와 동기화의 구현 계약은 [앱·라우팅·국제화](../../architecture/app-routing-i18n.md)를 따름. MP-02의 공용 설정·언어 동기화가 위 정책을 적용함.

### 음량과 즉시 적용

**확정 정책·목표:** 내부 음량은 0~1의 유한값·소수 1자리이며 두 번째 소수 자리에서 반올림함. 기본값은 0.5이고 기존 UI의 0~10 표시는 경계에서 변환함.

- 빠른 음량·모달·종소리는 같은 적용값을 즉시 사용함.
- 회원 저장은 서버의 정규화된 최종 응답으로 저장 결과를 확인함. 상세 요청·응답은 데이터 접근 문서를 따름.
- 값이 없을 때의 기본값을 회원의 직접 선택값처럼 임의 저장하지 않음.

### 저장 수명과 실패 복구

**확정 정책·목표:** 적용값과 저장값·저장 상태를 구분함.

회원 설정 부분 수정에서 생략과 명시적 `null`은 해당 필드의 기존 값 유지임. `null`을 언어 미선택 상태로 초기화하거나 음량 0으로 변경하는 명령으로 해석하지 않음. 최소 한 필드에 유효한 변경값이 필요함. 2026-11-14 사용자가 서버의 `null` 유지 동작을 수용하고 FE·문서 반영을 요청한 근거는 [SETTINGS-DEC-002](../decisions/settings.md#settings-dec-002--회원-설정-patch의-null-의미)에 기록함.

- 조회·저장 상태를 내부적으로 구분하되 모달의 로딩·성공·실패 안내와 조회·저장 재시도 버튼은 제공하지 않음.
- 조회 실패 상태에서 기본값으로 기존 서버 설정을 덮어쓰지 않음.
- 모달 닫기·앱 내부 이동 시 대기 변경의 저장을 시작하되 저장 때문에 이동을 막지 않음.
- 접속·로그인 때 필요한 초기 조회 이후 포커스 복귀·재연결·주기적 자동 재조회를 하지 않음.

**확정 정책:** 서버 저장은 500ms로 묶고 조작 완료 시 대기 변경을 저장함. 요청은 직렬 실행하며 요청 중 추가 변경은 최신값으로 이어 저장함. 실패하면 대기 변경을 유지함. 다음 직접 변경 때 이전 미저장값과 최신 변경을 합쳐 다시 저장하며 자동 반복·온라인 복귀 재시도는 하지 않음.

미저장·저장 중·실패 상태에서도 새로고침·탭 닫기·페이지 이동을 허용함. 설정 때문에 종료 경고를 요청하지 않으며 페이지 종료 후 초안 복원·서버 전달 성공을 보장하지 않음. 다른 기능의 토론·속기 이탈 보호는 별도 정책임.

일반 로그아웃 직전에는 최신 미저장 필드만 API로 발행하고 저장 완료·성공·실패와 관계없이 로그아웃을 진행함. 진행 중 저장도 기다리지 않으며 동시 요청의 서버 완료 순서와 최종 저장을 보장하지 않음. 로그아웃 API 자체의 실패 처리는 유지함. 계정 변경 후 이전 요청을 새 계정으로 재전송하지 않음.

### 문의·모달 조작과 로그아웃 경계

**확정 정책:** 문의 URL은 `VITE_GENERAL_INQUIRY_URL`·`VITE_TEMPLATE_REQUEST_URL`·`VITE_PARTNERSHIP_INQUIRY_URL`에서 읽음. trim 후 빈 항목과 빈 영역을 숨김. 일반 헤더는 MP-04에서 동일 설정을 사용함.

**확정 정책:** 중앙 모달과 내부 스크롤·포커스 가두기·복귀·닫기를 제공하며 열린 동안 본문 단축키를 차단함. 전체 화면에서의 실제 동작은 브라우저 검증과 구분함.

기본 타이머에서 진행 중 로그아웃의 경고·공유·마이크 정리는 페이지가 소유하고 설정 모달은 이를 위임하는 진입점임. MP-03의 준비를 MP-04에서 실제 화면에 연결했으며, 취소 시 진행 유지와 로그아웃 실패 시 인증을 먼저 지우거나 성공 이동하지 않는 목표를 따름. 공유 중단의 성공 확인·상태 복원은 MP-01 기본 통신의 완료 범위에 포함되지 않았음.

## 대표 사용 흐름·예시

아래는 목표 정책을 적용한 예시이며 실제 브라우저에서 확인한 동작은 아님.

- 계정 저장 언어가 한국어인 회원이 영어 링크를 방문하면 영어로 표시하되 계정 언어는 바꾸지 않음. 이후 언어 선택기에서 영어를 직접 선택하면 계정에 저장함. 근거는 [언어 우선순위](#표시-언어의-우선순위)임.
- 비회원 음량이 0.2인 브라우저에서 음량 0.8을 저장한 계정으로 로그인하면 계정 값을 사용함. 로그아웃하면 비회원의 0.2로 복귀함. 근거는 [계정 전환](#회원비회원과-계정-전환)임.

## 현재 구현과 목표의 차이

**구현에서 확인한 사실:** MP-02 로컬 구현 기준이며 실제 서버 연동·배포 완료를 의미하지 않음.

| 영역      | 현재 확인한 사실                                       | 남은 차이                                                     |
| --------- | ------------------------------------------------------ | ------------------------------------------------------------- |
| 회원 통신 | 설정 조회·부분 수정 API와 MSW가 있음                   | 실제 서버 저장·재로그인 검증이 필요함                         |
| 공용 설정 | 계정별 적용값·저장 큐·실패 복구를 공용 계층에서 관리함 | 다른 기기 실시간 동기화는 범위 밖임                           |
| 음량      | 빠른 조절·종소리·모달이 공용 값을 사용함               | MP-04에서 기본·피드백·사회자 투표의 설정 진입점을 연결했음    |
| 언어      | 자동 캐시를 끄고 링크·저장 언어·직접 선택을 구분함     | 실제 브라우저 이력·인증 복귀 검증을 별도로 수행함             |
| 설정 모달 | 일반 화면의 일반·문의·계정 영역을 구현함               | MP-04에서 타이머 설정을 연결했음. 청중은 언어·로그인만 제공함 |

근거는 [회원 API](../../../src/apis/apis/member.ts), [설정 조회 훅](../../../src/hooks/query/useGetMemberSettings.ts), [설정 변경 훅](../../../src/hooks/mutations/usePatchMemberSettings.ts), [종소리 훅](../../../src/page/TimerPage/hooks/useBellSound.ts), [i18n 초기화](../../../src/i18n.ts), [언어 선택기](../../../src/layout/components/header/LanguageSelector.tsx)임.

## 인접 기능과의 경계

| 기능                | 전역 설정과의 경계                                                                                      |
| ------------------- | ------------------------------------------------------------------------------------------------------- |
| 헤더                | 공용 언어·음량·설정 진입점을 표시함. 전체 탐색·레이아웃은 MP-04 범위임                                  |
| 타이머              | 공용 음량을 소비하고 언어 변경으로 실행을 재생성하지 않음. 진행 정책은 [타이머 위키](timer.md)가 소유함 |
| 속기·공유·답변 시간 | 활성화·인식 언어·답변 제한 시간은 토론 기능이 소유함. 전역 설정 저장 대상이 아님                        |
| 인증·로그아웃       | 로그인 진입·복귀와 토론 중 정리는 해당 기능이 소유함. 설정은 계정 전환 시 적용값·요청을 분리함          |

## 결정 근거와 보완 정책

### 목표 정책의 근거

기존 목표의 근거는 전체 작업 계획 4절의 헤더·설정 모달, 전역 설정·언어, 로그아웃 사양과 6절의 설정 지연 저장·화면 이탈 조건임. 해당 계획은 2026-11-11 사용자 답변을 반영했다고 명시함. 이번 대화에서 사용자는 MP-02 구현 전 전역 설정 위키를 작성해 기준으로 두도록 요청했음. 명시적 구현 제안은 확정 정책으로 승격하지 않았음.

[설정 결정 기록](../decisions/settings.md#settings-dec-001--mp-02-전역-설정과-저장-정책)은 이번 MP-02 정책 선택을 기록한 상태임. 후속 결정 시 실제 승인 주체·일자·근거와 해당 정책 절을 연결함. 확인되지 않은 과거 결정일·이유를 복원해 채우지 않음.

### MP-02에서 확정한 보완 정책

2026-11-12 MP-02 계획 수립 대화와 실제 사용 후 정책 수정 지시를 반영한 현행 동작임. 관련 근거는 [설정 결정 기록](../decisions/settings.md#settings-dec-001--mp-02-전역-설정과-저장-정책)에 남김.

| 항목               | 확정한 동작                                                                                                       |
| ------------------ | ----------------------------------------------------------------------------------------------------------------- |
| 초기 조회 실패     | 조작을 허용하고 직접 변경한 필드만 저장함. 기본값·건드리지 않은 필드는 저장하지 않음                              |
| 비회원 저장소 실패 | 탭의 적용값을 유지하며 다음 직접 변경 때 최신 미저장값을 다시 저장함. 별도 안내·재시도 버튼은 제공하지 않음       |
| 저장 실패          | 적용값과 미저장 변경을 유지하고 다음 직접 변경 때 함께 저장함. 자동 반복·온라인 복귀 재시도는 하지 않음           |
| 저장 시점          | 500ms로 묶고 언어 선택·음량 조작 완료·모달 닫기·내부 이동 때 대기 변경을 저장함                                   |
| 상태 표시          | 설정 조회·저장 상태와 재시도 버튼을 모달에 표시하지 않음. 진입점 경고·전역 알림도 추가하지 않음                   |
| 페이지 종료        | 미저장·저장 중·실패에도 즉시 이탈을 허용함. 설정 종료 경고·종료 후 초안 복원은 제공하지 않음                      |
| 문의               | 공용 환경 변수의 trim 후 빈 항목과 빈 영역을 숨김                                                                 |
| 모달               | 중앙 배치·내부 스크롤·포커스 가두기와 복귀를 제공함. Escape·바깥 클릭·닫기 버튼으로 저장 중·실패에도 닫을 수 있음 |
| 기존 브라우저 값   | `i18nextLng`는 직접 선택으로 승계하지 않음. 정상 `timer-volume`은 비회원 값으로 유지함                            |
| 일반 로그아웃      | 최신 미저장 변경을 API로 발행하고 완료를 기다리지 않음. 저장 실패·대기 때문에 로그아웃을 차단하지 않음            |

설정 진입점은 MP-02에서 일반 화면에 연결함. MP-04에서 기본·피드백·사회자 투표 타이머에 설정을 연결했으며 청중은 언어·로그인만 제공함. 기본 타이머의 안전한 로그아웃은 준비된 중단 콜백에 위임함.

## 검증 근거와 한계

[회원 API 테스트](../../../src/apis/apis/member.test.ts)와 [설정 훅 테스트](../../../src/hooks/query/useGetMemberSettings.test.tsx)는 HTTP·모의 저장·계정별 캐시·지연 응답·재시도 기반의 근거임. 모달·언어 우선순위·비회원 복귀 구현 완료의 근거는 아님.

MP-02에서는 위 목표와 질문 해소 결과로 회원·비회원 전환, 링크·저장 언어 충돌, 조회 중 직접 선택, 공용 음량, 모달 닫기·화면 이동 중 저장, 실패 후 직접 변경 재저장·저장 비대기 로그아웃·이탈 허용, 포커스·단축키·전체 화면을 검증해야 함. 실제 서버 저장·재로그인과 브라우저 저장소 실패도 모의 검증과 구분함.

MP-02 자동 테스트의 근거는 공용 설정·저장 큐·모달·언어 동기화 테스트에 있음. 실제 브라우저의 전체 화면·지원 브라우저 확인과 인증된 서버 저장·재로그인은 자동 테스트와 구분함. 배포 완료를 의미하지 않음.

## MP-03 로그아웃 위임 계약

토론 전용 `onLogout`을 전달하면 설정 모달은 자기 창을 닫고 콜백에 위임함. 경고 확인·설정 발행·실패 복구는 콜백이 소유하며 취소 전에 별도 설정 발행을 하지 않음. 일반 로그아웃의 기존 발행·응답 비대기는 유지함. 실제 타이머 연결과 기록 폐기 정책은 [토론 메뉴 위키](debate-controls.md#로그아웃과-기록)를 따름.
