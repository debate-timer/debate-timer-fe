# 헤더와 탐색

## 목적과 제공 기능

일반 사용자·사회자·청중이 각 화면에 필요한 정보와 조작에 접근하도록 헤더를 구분하고 소개·시간표·토론 기록을 독립된 경로로 제공함.

**지식 상태:** 2026-11-14 MP-04 계획 대화의 사용자 선택과 구현 승인에 따른 확정 정책임. 로컬 구현과 실제 서버 검증·배포 완료는 구분함. 승인 근거와 선택의 한계는 [SHARED-DEC-001](../decisions/shared.md#shared-dec-001--mp-04-헤더탐색청중-완료-연결)에 기록함.

## 기본 동작

| 역할   | 적용 화면                                   | 제공 정보·조작                                                                             |
| ------ | ------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 일반   | 아래 역할 이외의 화면과 기록 상세·공유 기록 | 소개·대시보드·기록·템플릿·문의, 언어·설정·비회원 로그인임                                         |
| 타이머 | 기본 타이머·피드백·사회자 투표              | 이름·주제, 전체 화면·음량·설정임. 토론 메뉴·기능 상태·기존 도움말은 기본 타이머에만 제공함 |
| 청중   | 라이브·라이브 종료·투표 참여·완료           | 로고·서비스명, 이름·주제, 언어·비회원 로그인임. 사회자 조작·설정·로그아웃은 제공하지 않음  |

일반·청중 헤더의 로고는 현재 언어의 소개로 이동함. 일반 헤더는 소개 → 대시보드 → 기록 → 템플릿 → 문의 순서와 언어 → 설정 → 로그인 순서를 따름. 일반 화면에서 소개로 이동할 때의 기존 게스트 시간표 정리 동작을 유지함. 로그아웃은 설정 모달에서만 제공함.

이름은 보조 정보·주제는 주요 정보로 위아래 표시함. 빈 값은 대체 문구를 사용하며 키보드·클릭·터치로 전체 내용을 헤더 안에 펼침. 좁은 화면은 정보·조작·탐색을 재배치하며 긴 내용을 숨긴 채 hover에 의존하지 않음. 로딩·오류에도 해당 역할의 헤더와 가능한 조작을 유지함.

문의는 [전역 설정](settings.md)의 공용 링크 설정을 재사용함. 설정하지 않은 항목과 비어 있는 메뉴는 숨김.

템플릿 메뉴는 `/templates`로 이동하며 로그인과 기능 권한 없이 제공함.

## 경로와 인증

- 소개는 `/`, 시간표는 `/dashboard`, 기록은 `/records`임. 시간표·기록은 회원 전용임. 기록 메뉴·목록·상세는 기존 `TRANSCRIPT` 권한을 유지하고 권한 없는 회원은 대시보드로 이동함.
- 비회원의 시간표·기록 선택은 로그인 확인을 제공함. 보호 경로 직접 방문은 소개에서 같은 안내를 제공함. 취소하면 로그인하지 않음. 게스트 시간표가 있으면 유지 여부를 함께 선택함.
- 로그인 후 현재 탭의 허용된 목적지를 한 번 소비함. 선택한 시간표·기록 또는 청중의 현재 경로로 복귀하며 query·hash를 보존함. 게스트 시간표 유지의 `/share` 흐름이 우선하며 기본 성공 목적지는 `/dashboard`임.
- 로그아웃·인증 만료·홈 복귀는 `/`임. 브라우저 뒤로 가기에 같은 경로를 다시 삽입하지 않음. OAuth·이전 링크 호환 이동은 replace를 사용함.
- `/home`은 `/`로, `/?tab=records`·`/dashboard?tab=records`는 `/records`로 이동함. 언어와 소비하지 않은 query·hash를 보존함.

## 완료·종료 안내

- 투표 제출 성공은 `/vote/end?pollId={id}`로 이동함. 기존 공개 조회 캐시를 재사용하며 정보 조회로 투표를 재제출하거나 제출 성공을 새로 판정하지 않음.
- 라이브는 `/live/:id/end`를 유지함. 실제 수신한 `ABORT`·`FINISHED` 사유만 해당 방문에 보존하며 언어 변경·로그인 복귀에도 전달함. 사유 없는 직접 방문은 중립적인 공유 종료 안내를 표시함. 종료 페이지에서 소켓을 열지 않음.
- 캐시가 없으면 유효한 식별자로 기존 공개 API를 조회함. 조회 실패·삭제·만료에도 완료 안내와 헤더를 유지하고 정보 재시도를 제공함. ID 없는 과거 투표 완료 링크는 조회하지 않음.
- 페이지 닫기는 `window.close()`를 시도하고 닫히지 않으면 소개로 이동함. 서버의 종료 사유 보장 범위는 [실시간 통신](../../architecture/realtime.md#mp-04와-be-pr-328의-정합-범위)을 따름.
