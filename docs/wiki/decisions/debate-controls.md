# 토론 메뉴와 진행 수명 결정 기록

### DEBATE-CONTROLS-DEC-001 — MP-03 준비 범위와 중단 정책

- 결정일: 2026-11-12, 상태: 승인임. 작업: MP-03, [PR #561](https://github.com/debate-timer/debate-timer-fe/pull/561)임.
- 승인 근거: MP-03 계획 대화에서 사용자가 공유의 현재 발행 범위 축소, 답변 시간 기존 제안 적용, 로그아웃 시 로컬 초안 폐기, 실제 페이지 연결의 MP-04 이관을 선택한 뒤 해당 계획의 구현을 요청했음.
- 독립 UI·상태 훅·Story·연결 계약을 MP-03에서 준비하고 헤더·기존 진입점 교체는 MP-04에서 수행함.
- 공유 끄기는 `ABORT` 발행 시도 후 로컬 연결을 종료함. 서버 성공 확인을 선행 조건으로 두는 안 대신 현재 통신 기반을 사용함. 서버 중단 확정·상태 복원·새 청중 차단은 보장하지 않으며 후속 요구로 유지함.
- 답변 시간은 최초 켜짐·30초와 15/30/45/60초를 사용함. 로그아웃은 중단 초안 보존안 대신 미제출 로컬 초안을 폐기함. 실패해도 폐기한 기록과 진행 기능을 자동 복원하지 않음.
- 적용 정책은 [토론 메뉴와 진행 수명](../feature/debate-controls.md)이 소유함. 이 승인은 실제 서버 연동·운영 배포의 증거가 아님.
