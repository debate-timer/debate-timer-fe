# 타이머 결정 기록

현행 정책은 [타이머 진행](../feature/timer.md)에서 관리하며, 결정 기록의 작성·상태 관리는 [위키 유지보수 기준](../maintenance.md#결정-기록을-남기는-조건)을 따름.

### TIMER-DEC-001 — 기존 질문 여섯 건의 정책 확정

2026-11-12 · 승인 · 근거: 사용자가 이 채팅에서 타이머 미확정 질문 1~6에 답변하고 정책으로 반영하도록 요청했음.

| 결정 | 이유·배경 | 현행 정책 |
| --- | --- | --- |
| A/L·Enter 키로 진영 전환을 지원하고 마우스 전환은 금지함 | 기존 의도를 확인했음 | [단축키](../feature/timer.md#단축키시간-경고) |
| 방향키로 차례를 이동할 수 없음 | 과거에 허용했으나 합의로 막았음 | [단축키](../feature/timer.md#단축키시간-경고) |
| 게스트 종료 안내를 열면 타이머를 일시정지함 | 기존에 미정이었던 동작을 이번에 결정했음 | [종료](../feature/timer.md#차례-이동과-종료) |
| 자유토론 완료는 팀당 시간 소진으로 정의함 | 턴이 끝나도 팀당 시간이 남으면 다음 발언이 가능함 | [자유토론](../feature/timer.md#자유토론-타이머) |
| 피드백 타이머는 테이블에 추가할 수 없고 토론 종료 후에만 진입함 | 사용자 구성 항목과 종료 후 기능을 구분함 | [피드백](../feature/timer.md#피드백-타이머) |
| 테이블 전체에 `speechType === '작전 시간'`인 항목이 없을 때 보조 작전 시간 버튼을 표시함 | 정확한 문자열 판별이 의도임을 확인했음 | [작전 시간](../feature/timer.md#보조-작전-시간) |
