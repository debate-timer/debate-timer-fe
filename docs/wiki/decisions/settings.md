# 전역 설정 결정 기록

현행 정책은 [전역 설정](../feature/settings.md)에서 관리함. 기록 조건·번호·상태·대체 관계는 [위키 유지보수 기준](../maintenance.md#결정-기록을-남기는-조건)을 따름.

현재는 작성 양식만 준비했으며 실제 결정 기록은 없음. 첫 실제 기록은 `SETTINGS-DEC-001`부터 부여함. 아래 `NNN`은 자리 표시자이며 결정 번호를 예약하거나 승인 사실을 의미하지 않음.

## 작성 양식

아래 양식을 복사해 독립적으로 바뀔 수 있는 결정마다 기록함. 상태는 실제 결정에 맞게 작성하고 근거가 없는 승인일·주체·이유를 채우지 않음.

```markdown
### SETTINGS-DEC-NNN — <결정 제목>

결정일: 미정 · 상태: 제안 · 근거: <제안 또는 승인·기각 주체와 문서·이슈·채팅 지시>

- 결정: <선택한 동작과 적용 조건을 작성함>
- 이유: <제공된 근거와 판단에 필요한 이유를 작성함>
- 관련 정책: [<정책 절 제목>](../feature/settings.md#<실제-정책-절-앵커>)
```

상황·대안·한계·대체 관계는 실제 필요한 기록에만 추가함. 단순 확인에 별도 이유가 제공되지 않았다면 이유 항목을 생략함. 승인 후 관련 정책 절과 근거 링크를 함께 갱신함.

미확정 질문은 [기능 문서의 질문 목록](../feature/settings.md#mp-02에서-확인할-질문)에서 관리함. 답변 없이 실제 승인 기록으로 복사하지 않음.
