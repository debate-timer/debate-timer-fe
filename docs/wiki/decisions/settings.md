# 전역 설정 결정 기록

현행 정책은 [전역 설정](../feature/settings.md), 기록 단위·작성 기준은 [위키 유지보수](../maintenance.md)를 따름. 정책 승인과 구현·배포 완료는 구분함.

### SETTINGS-DEC-001 — MP-02 전역 설정과 저장 정책

결정일: 2026-11-12 · 상태: 승인 · PR: [#560](https://github.com/debate-timer/debate-timer-fe/pull/560) · 작업: MP-02

근거: MP-02 계획 수립 시 사용자 선택·구현 승인, 실제 사용 후 저장 상태·이탈·로그아웃 정책 수정 지시, 실패 후 다음 직접 변경 재저장 선택에 따름. 사용자가 결정 기록을 PR 단위로 통합하도록 요청해 이번 작업의 임시 기록 10건을 한 건으로 정리했음.

| 결정 영역 | 최종 결정·적용 범위 |
| --- | --- |
| 초기 조회 실패 | 조작을 허용하고 직접 변경한 필드만 저장함. 기본값으로 기존 계정 설정을 덮어쓰지 않음 |
| 저장 시점·복구 | 500ms로 묶고 조작 완료·모달 닫기·내부 이동 때 저장함. 실패 시 적용값·미저장 변경을 유지하고 다음 직접 변경 때 최신값을 합쳐 재저장함. 자동 반복·온라인 복귀 재시도는 하지 않음 |
| 상태 표시·이탈 | 모달의 설정 조회·저장 상태와 재시도 버튼을 제공하지 않음. 미저장·저장 중·실패 때문에 페이지 이탈을 차단하거나 종료 경고를 요청하지 않음. 전역 알림·종료 후 초안 복원은 추가하지 않음 |
| 일반 로그아웃 | 직전에 최신 미저장 필드를 발행하고 완료를 기다리지 않음. 최종 저장·동시 요청의 서버 완료 순서를 보장하지 않음. 계정 격리와 로그아웃 API 자체의 실패 처리는 유지함 |
| 문의·모달 | 공용 환경 변수의 빈 문의 항목·영역을 숨김. 중앙 모달·내부 스크롤·포커스 가두기와 복귀·Escape·바깥 클릭·닫기 버튼을 제공함 |
| 기존 값·화면 연결 | 자동 감지와 직접 선택이 섞인 `i18nextLng`는 승계하지 않음. 정상 `timer-volume`은 비회원 값으로 유지하며 회원 서버로 자동 이전하지 않음. MP-02 진입점은 일반 화면에 연결하고 타이머·청중 헤더 연결은 후속 작업으로 둠 |

작업 중 조정: 처음 선택한 모달 내 상태·수동 재시도, 미저장 종료 경고, 로그아웃 전 저장 완료 대기는 실제 사용 후 사용자 지시로 철회했음. 최종 정책은 저장 완료보다 즉시 이탈·로그아웃을 허용하며 저장 성공을 보장하지 않음. 토론·속기의 별도 이탈 보호는 변경하지 않음.
